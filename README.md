# customer-crud-python
Simple CRUD client management system (create, read, update, delete) in Python using JSON for data storage. 

## Features
- Register new clients
- List all clients
- Search clients by CPF
- Update client information
- Delete clients
- Data persistence using JSON

## Technologies
- Python
- JSON file storage
